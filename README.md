# Baby Reigns

**La Nuit des Petits Tyrans** — un jeu de décisions parentales nocturnes inspiré du principe de choix gauche/droite de *Reigns*.

## Jouer

https://sebastien-fresse-revvity.github.io/baby-reigns/

## Gameplay

- 30 situations parentales, avec 12 décrets uniques par partie.
- Trois phases de nuit et une difficulté progressive.
- Quatre jauges : sommeil, propreté, stress et réserves.
- Série de sang-froid pour récompenser les décisions équilibrées.
- Une Grâce royale par partie pour éviter une défaite brutale.
- Statistiques et succès conservés localement.
- Contrôles tactiles, souris et clavier.

Le déploiement GitHub Pages est automatisé depuis `main` via GitHub Actions.
